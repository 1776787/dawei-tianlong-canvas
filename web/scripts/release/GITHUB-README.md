# 大威天龙画布

以画布组织图片、提示词、视频与创作流程的本地创作工作台。

## 下载与运行

在本仓库的 **Releases** 页面下载 Windows x64 便携版 ZIP。
解压全部文件后双击 `start.vbs`，浏览器自动打开工作台。
无需安装 Node.js 或 npm；生成服务需要自行配置 API。
结束使用时双击 `stop.vbs` 关闭本地服务。

## 功能

- 无限画布、节点连接与项目管理
- 图片和视频创作、资产整理、提示词图鉴
- RunningHub 工作流与视频时长编辑
- 导演台与场景预演

## 数据

项目与配置保存在使用者浏览器本地。升级前请导出备份。
本项目不附带可共享的生成服务密钥。
