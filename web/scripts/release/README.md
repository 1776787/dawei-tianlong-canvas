# 大威天龙画布 · Windows 便携版

## 启动

1. 将整个 ZIP 解压到可写目录，保留文件夹结构。
2. 双击 `start.vbs`，服务在后台启动，就绪后打开默认浏览器。
3. 在“配置”中填写自己的服务地址、模型和 API Key，RunningHub Key 也需自行配置。
4. 退出时先保存作品，再双击 `stop.vbs`。关闭浏览器不会停止后台服务。

默认地址为 `http://localhost:3001/`，可通过 `APP_PORT` 更换端口。无需安装 Node.js 或 npm。
如果端口被旧版本占用，请先关闭旧版本。可设置环境变量 `APP_PORT` 指定其他端口；启动和停止时应使用相同值。

## 数据与升级

画布、资产和 API 配置保存在当前浏览器的本地存储中，不保存在软件 ZIP 中。
更换浏览器、端口或将 localhost 改成 127.0.0.1，会使用不同的数据空间。
升级前请在配置的备份页面导出数据。不要把带有个人数据或密钥的备份公开上传。
升级时先停止旧服务，再解压并启动新版；保持原浏览器和地址。

## 使用条件

- Windows x64，现代浏览器；网络生成服务需要联网，费用由所选服务商收取。
- 本地服务只监听本机地址，不提供局域网共享入口。
- 启动失败可运行 `diagnose.bat` 查看信息；服务日志位于 `logs`，不要公开上传日志。
- 本包未进行代码签名。遇到系统安全提示，请核实来源与 SHA-256，不要关闭系统安全防护。
